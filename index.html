01 SECURITY + ML

PhishGuard AI — Adversarial Phishing URL Detector

S / SITUATION

Phishing attacks bypassed traditional signature-based filters because adversaries continuously rotate domains and obfuscate URL structures — rendering static blocklists obsolete within hours.

T / TASK

Design a detection system that generalizes to novel phishing patterns without retraining, using behavioral and structural URL features rather than blacklist lookups.

A / ENGINEERING ARCHITECTURE

Built a 4-model ensemble — Gradient Boosting, Random Forest, Neural Net (MLP), and SVM — running simultaneously with consensus scoring. Engineered 30+ lexical and structural features — URL entropy, subdomain depth, Top-Level Domain (TLD) rarity, obfuscation character presence — making the model robust to adversarial perturbations. Added a confidence-threshold guardrail to route uncertain predictions to human review rather than defaulting to binary classification. Deployed as a Flask REST API with a live web dashboard showing multi-model comparison charts and confidence intervals.

R / RESULTS

94% detection accuracy on held-out test set. False negative rate kept below 3% through asymmetric cost tuning. Live at phishing-detector-9xr8.onrender.com — paste any URL and see 4 models analyze it in real time.

02 GEN AI + RAG

Enterprise RAG Pipeline with LangChain + Azure OpenAI

S / SITUATION

Enterprise knowledge systems at Manulife contained 100,000+ unstructured documents. Large Language Model (LLM) responses without grounding produced confident but factually incorrect answers — an unacceptable risk in financial services.

T / TASK

Architect a production-grade Retrieval-Augmented Generation (RAG) system that grounds GPT-4o responses exclusively on verified enterprise data, with measurable hallucination reduction and audit traceability.

A / ENGINEERING ARCHITECTURE

Chose chunked embedding + vector retrieval over fine-tuning for two architectural reasons: (1) fine-tuning encodes knowledge statically and cannot reflect document updates without costly retraining; (2) RAG preserves source provenance, enabling citation-level auditability required by financial compliance teams. Implemented semantic chunking rather than fixed-size chunking to preserve contextual coherence across document boundaries. Built a LangChain orchestration layer with a hallucination circuit-breaker — if retrieval similarity fell below threshold, the system surfaced uncertainty rather than fabricating an answer.

R / RESULTS

Reduced hallucinated responses by design through grounding constraints. Automated 3 manual reporting workflows. System consumed by compliance and analytics teams across the enterprise.

AI Code Security Analyzer Dashboard

S / SITUATION

Manual code review for security vulnerabilities is slow, inconsistent, and scales poorly with codebase growth. Teams needed automated risk detection across Python, Ruby, and JavaScript — including entire GitHub repositories.

A / ENGINEERING ARCHITECTURE

Built a Ruby on Sinatra web backend that accepts file uploads (.rb, .py, .js) or GitHub repository URLs — cloning the repo and scanning all files automatically.
